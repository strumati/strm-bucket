# Strumat Buckets (`strm-bucket`)

> High-performance, S3-compatible object storage built for speed, scalability, and simplicity.

Strumat Buckets is a lightweight and efficient object storage service that provides full S3-compatible APIs for storing, retrieving, and managing files at scale. Designed for modern cloud-native applications, it delivers fast performance, reliable durability, and seamless integration with existing S3 tooling.

---

## Features

- ⚡ **High Performance** — Optimized for fast uploads, downloads, and concurrent workloads
- 🪣 **S3 Compatible API** — Works with AWS SDKs, MinIO clients, and existing S3 tools
- 🔒 **Secure by Default** — Access controls, authentication, and encrypted transport support
- 📦 **Scalable Storage** — Store anything from small assets to massive datasets
- 🌐 **Cloud-Native Ready** — Deploy on containers, Kubernetes, bare metal, or VMs
- 🔄 **Multipart Uploads** — Efficient handling of large file uploads
- 🧩 **Easy Integration** — Drop-in replacement for many S3-based workflows
- 📈 **Built for Reliability** — Consistent object access and durable storage architecture
